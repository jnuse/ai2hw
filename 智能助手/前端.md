
# 智能职场助手前端实现文档

## 1. 概述

智能职场助手是一个基于微信小程序的智能问答平台，旨在为职场人士提供智能化的工作建议和解决方案。本文档详细描述了前端的实现方案、架构设计和核心功能。

## 2. 技术栈

- **框架**: Vue.js + uni-app
- **UI组件**: 自定义组件 
- **状态管理**: Vue组件内状态管理
- **网络请求**: 自定义request模块
- **本地存储**: uni-app Storage API

## 4. 核心模块设计

### 4.1 配置模块 (config.js)

配置模块集中管理应用的全局配置，包括:
- API基础URL
- 本地存储键名
- 环境配置(开发/生产)
- Token过期时间

配置示例:
```javascript
export default {
  APP_NAME: '智能职场助手',
  BASE_API: 'http://localhost:5000/api',
  TOKEN_KEY: 'token',
  USER_INFO_KEY: 'userInfo',
  HISTORY_KEY: 'chatHistory',
  TOKEN_EXPIRE_HOURS: 24
};
```

### 4.2 网络请求模块 (utils/request.js)

封装uni-app的网络请求API，实现:
- 请求拦截器: 自动添加Token等认证信息
- 响应拦截器: 统一处理API响应格式和错误
- HTTP方法封装: GET、POST、PUT、DELETE等
- 错误处理机制: 包括Token失效处理

对外暴露的接口:
```javascript
export default {
  get(url, data, options),
  post(url, data, options),
  put(url, data, options),
  delete(url, data, options)
};
```

### 4.3 存储模块 (utils/storage.js)

封装uni-app的本地存储API，提供:
- 带过期时间的存储机制
- 用户信息存储与获取
- 聊天历史记录管理
- 时间格式化工具

主要功能:
```javascript
export default {
  set: uni.setStorageSync,       // 直接存储
  get: uni.getStorageSync,       // 直接获取
  setWithExpire(),               // 带过期时间的存储
  getWithExpire(),               // 自动处理过期的获取
  user: {                        // 用户相关存储
    setUserInfo(),
    getUserInfo(),
    clearUserInfo(),
    isLoggedIn()
  },
  chat: {                        // 聊天相关存储
    saveChat(),
    getChat(),
    getChatList(),
    deleteChat()
  }
};
```

## 5. 页面实现

### 5.1 登录页面 (pages/login/login.vue)

登录页面提供两种登录方式:
- 账号密码登录
- 微信一键登录

主要功能:
1. 用户名密码输入验证
2. 调用后端登录API
3. 保存Token和用户信息
4. 登录后跳转到聊天页面

交互流程:
```
用户输入 -> 前端验证 -> 调用API -> 获取Token -> 存储Token -> 跳转页面
```

### 5.2 聊天页面 (pages/chat/chat.vue)

聊天页面是应用的核心交互界面，提供:
1. 消息发送与接收
2. 历史消息显示
3. 示例问题快速提问
4. 导航到历史记录页面

数据结构:
- `messageList`: 当前对话的消息列表
- `conversationId`: 当前对话ID，用于关联历史记录
- `exampleQuestions`: 示例问题列表

关键功能:
1. `sendMessage()`: 发送消息并获取AI回复
2. `loadHistoryConversation()`: 加载历史对话
3. `parseHistoryContent()`: 解析历史对话内容
4. `showExamples()`: 显示问题示例

消息格式:
```javascript
{
  sender: 'user|assistant',  // 发送者
  content: '消息内容'         // 消息内容
}
```

### 5.3 历史记录页面 (pages/history/history.vue)

历史记录页面展示用户的历史对话列表，提供:
1. 分页加载历史记录
2. 查看历史对话详情
3. 删除历史记录
4. 下拉刷新和上拉加载更多

数据结构:
- `historyList`: 历史记录列表
- `page`: 当前页码
- `totalCount`: 总记录数
- `hasMore`: 是否有更多数据

关键功能:
1. `loadHistoryList()`: 加载历史记录列表
2. `viewHistoryDetail()`: 查看历史记录详情
3. `deleteHistory()`: 删除历史记录
4. `loadMoreHistory()`: 加载更多历史记录

### 5.4 调试页面 (pages/debug/history-debug.vue)

调试页面用于开发阶段调试历史记录解析问题，提供:
1. 通过ID加载历史记录
2. 查看原始内容
3. 解析内容并预览效果

## 7. 通信流程

### 7.1 前后端通信

前端与后端的通信采用RESTful API风格，主要流程:

1. **登录流程**:
   ```
   前端 -> /api/login(用户名密码) -> 后端验证 -> 返回Token -> 前端存储Token
   ```

2. **发送消息流程**:
   ```
   前端 -> /api/chat(消息内容+会话ID) -> 后端处理 -> 返回AI回复 -> 前端展示
   ```

3. **获取历史记录流程**:
   ```
   前端 -> /api/history(页码+每页条数) -> 后端查询数据库 -> 返回记录列表 -> 前端展示
   ```

4. **查看历史详情流程**:
   ```
   前端 -> /api/history/{id} -> 后端查询数据库 -> 返回对话内容 -> 前端解析展示
   ```

### 7.2 数据格式

所有API返回的数据遵循统一格式:
```json
{
  "code": 0,         // 0表示成功，非0表示失败
  "message": "xxx",  // 成功或失败的消息
  "data": {}         // 返回的数据，可能为空
}
```

## 8. 状态管理

应用采用简单的状态管理方案:
1. **全局状态**: 通过本地存储(Storage)管理
   - 用户Token
   - 用户信息
   - 是否登录

2. **页面状态**: 在组件内通过data属性管理
   - 消息列表
   - 历史记录
   - 加载状态

3. **组件通信**: 通过props和events进行父子组件通信

## 15. 附录

### 15.1 目录规范

- `pages`: 所有页面组件
- `components`: 可复用的组件
- `utils`: 工具类函数
- `api`: API接口封装
- `static`: 静态资源文件

### 15.2 命名规范

- 文件名: 小写字母，多单词用连字符连接(kebab-case)
- 组件名: 大驼峰命名法(PascalCase)
- 方法名: 小驼峰命名法(camelCase)
- CSS类名: 小写字母，多单词用连字符连接(kebab-case)

### 15.3 常见问题解决

- 白屏问题: 检查路由配置与组件注册
- 图片加载失败: 检查图片路径与文件名
- API调用失败: 检查网络连接与API地址配置
